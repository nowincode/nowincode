# Morphing Verification Code Input

Inspired by a design by @sucodeee (https://x.com/sucodeee/status/2107420636113191248).

Piece page: https://nowincode.com/library/morphing-verification-code-input

## React Native (Expo)

Entry: `01_ui_code_input.tsx`

Install: `npx expo install expo-blur react-native-svg`

Built and tested on Expo SDK 54 (React Native 0.81, Reanimated 4.1, React Native Skia 2.2). In an SDK 54 project `npx expo install` picks matching versions. Newer SDKs are not verified yet.

## Web

Open `web/01_ui_code_input.html` in a browser. It is a self-contained reference build of the same motion and timing.
