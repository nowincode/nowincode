# Sticky Section Headers with Progressive Blur

Inspired by a design by @leon7hao (https://x.com/leon7hao/status/2120047269340946932).

Piece page: https://nowincode.com/library/sticky-section-headers-with-progressive-blur

## React Native (Expo)

Entry: `LodyStickyBlurList.tsx`

Install: `npx expo install @react-native-masked-view/masked-view expo-blur expo-linear-gradient react-native-svg`

Built and tested on Expo SDK 54 (React Native 0.81, Reanimated 4.1, React Native Skia 2.2). In an SDK 54 project `npx expo install` picks matching versions. Newer SDKs are not verified yet.

## Web

Open `web/03_motion_sticky_blur_list.html` in a browser. It is a self-contained reference build of the same motion and timing.
