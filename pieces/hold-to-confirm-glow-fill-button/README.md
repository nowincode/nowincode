# Hold-to-Confirm Glow Fill Button

Inspired by a design by @a_cucos (https://x.com/a_cucos/status/2107894726628127140).

Piece page: https://nowincode.com/library/hold-to-confirm-glow-fill-button

## React Native (Expo)

Entry: `03_motion_hold_commit.tsx`

Install: `npx expo install @shopify/react-native-skia expo-haptics react-native-svg`

Built and tested on Expo SDK 54 (React Native 0.81, Reanimated 4.1, React Native Skia 2.2). In an SDK 54 project `npx expo install` picks matching versions. Newer SDKs are not verified yet.

## Web

Open `web/03_motion_hold_commit.html` in a browser. It is a self-contained reference build of the same motion and timing.
