# Checkbox Spike Strikethrough Todo

Inspired by a design by @barret_jessy (https://x.com/barret_jessy/status/2114756442804949307).

Piece page: https://nowincode.com/library/checkbox-spike-strikethrough-todo

## React Native (Expo)

Entry: `04_motion_todo_check_strike.tsx`

Install: `npx expo install expo-blur react-native-svg`

Built and tested on Expo SDK 54 (React Native 0.81, Reanimated 4.1, React Native Skia 2.2). In an SDK 54 project `npx expo install` picks matching versions. Newer SDKs are not verified yet.

## Web

Open `web/04_motion_todo_check_strike.html` in a browser. It is a self-contained reference build of the same motion and timing.
